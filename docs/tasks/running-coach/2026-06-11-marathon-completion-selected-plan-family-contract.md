# Marathon Completion Selected-Plan Family Contract - Historical Record

Date: 2026-06-11
Owner: Running Coach
Status: historical; separate deterministic family superseded by selected-distance AI authoring

## Original Problem

Marathon Base could build aerobic durability but could not honestly promise preparation for the
selected full-marathon distance. Stretching that base-only program into a race endpoint would have
misrepresented both the training process and runner readiness.

## Decision At The Time

The document proposed a separate deterministic `Marathon Completion` family with long adaptation,
base, durability, completion-build, taper, and exact `42195m` endpoint phases. It deliberately
separated finish-focused completion from Marathon Base and from target-time or performance
marathon training.

The separate deterministic family, fixed 20-130 week horizon matrix, identity inventory, and backend
composition rules are no longer current.

## Durable Lessons

- A selected Marathon goal requires an honest exact `42195m` endpoint when the draft is accepted.
- Full-distance completion, general aerobic base, and performance/target-time preparation are
  different coaching promises.
- Marathon preparation needs plausible adaptation, recurring cutbacks, protected long-run
  progression, taper, and meaningful midweek support; it must not be stretched easy/long filler.
- Low availability or conservative load should reduce compression and intensity, not erase marathon
  identity.
- An impossible compressed goal must not be silently downgraded, relabeled, or represented as race
  readiness.
- Completion-focused training must not invent race-pace certainty, personal BPM, medical claims, or
  elite-performance programming.

## Supersession Boundary

Current Quick setup sends the selected Marathon distance and runner facts to the AI-authored
plan-first path. AI authors the full process; backend validates exact endpoint, calendar, target,
review, and persistence truth. Marathon Base is not a current fallback family, and a separate
deterministic Marathon Completion builder is not the current owner.

Do not use this file to:

- restore deterministic family selection or horizon tables;
- treat Marathon Base as the current contrast or fallback;
- make backend author completion phases or repair AI coaching;
- reject truthful AI-authored estimated pace or immutable accepted-profile BPM commands.

stable path.
